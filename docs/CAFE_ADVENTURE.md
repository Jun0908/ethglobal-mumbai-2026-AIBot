# 会話の選択で進む、Miraのチャイデート

2026-11-07 JST。まずMiraのカフェ1ルートで、会話と進行を一つにする改善を実装した。

## 遊び方

ホームの「Miraのチャイデートを遊ぶ」から開始する。会話の下の選択肢だけで最後まで進める。

1. お互いのチャイを選ぶ提案を受ける。
2. 今日飲みたい味を伝え、Miraに自分の一杯を選んでもらう。
3. Miraの言葉を手がかりに、彼女の一杯を選ぶ。選ぶ前に質問もできる。
4. 二つの味を混ぜるか、それぞれの一杯を楽しむか決める。
5. 今日の体験に名前をつけ、思い出カードを作る。
6. 次の一杯を一緒に選びたいと伝えるか、お礼で今日を締めくくる。

寄り道の質問と自由会話は任意。会話回数だけで場面を飛ばさない。結末後も会話でき、新しいデートでは別の選び方を試せる。

## 変わった点

- Miraの新規デートでは「次の展開を選ぶ」を撤去。返答候補にサーバー管理の行動IDを結び、選択が同時に出来事を進める。
- カップの中身、6段階の進捗、場面の説明、雨上がりの色、思い出カードで結果を見せる。スマートフォンでも現在の会話の上に進捗を表示する。
- 自分の好みはMiraが一杯を選ぶ台詞と最後の返事に反映。Miraの希望と違う一杯には、感謝とともに彼女自身の希望を返す。
- 共同ブレンド／それぞれの一杯という二つの結果で、思い出と次回の提案が変わる。名前2種類と最後の返事も保存する。どちらも有効な結末で、好感度の減点はない。
- 画面に存在しない看板を当てるクイズを使わず、説明された二つのメニューと本人の言葉で判断できるようにした。
- 過去の会話は開いて読める形にし、通常は直近の往復と選択肢を表示。引用から過去の会話へ移動するときは履歴を開く。
- 返答後は相手の最新メッセージへフォーカスを移し、Tabで次の選択肢へ進める。
- JP/ENの切り替えでは候補と表示を更新し、既存の会話・選んだ味・思い出を保持する。出力言語は画面のJP/EN指定に従う。

## AIと状態管理

`src/lib/cafe-adventure.ts` が許可された行動、段階、味、結果、思い出を管理する。主要な選択への台詞は両言語の台本で確定し、余分なLLM待ち時間なしで進む。進行と結果をLLMの推測に任せない。

自由会話は既存のOpenAI接続を使い、現在の段階・確定した出来事・Miraの好み・実行可能な提案を文脈に含める。通常の会話から勝手に出来事を成立させないよう指示する。2往復以上の寄り道では、続きの選択肢を案内しながら話し続ける余地を残す。明示的な休憩は短い返事にする。

自由入力の行動認識は保守的な範囲に限定した。例えば現在の段階で「甘いのがいい」「混ぜよう」と明示すれば進む。否定、推量、過去、引用、未対応の表現で勝手に進めない。認識されない表現でも表示された選択肢から実行できる。一般的な自然言語理解を完全に保証するものではない。

候補のID、言語、revision、clientTurnIdを検証する。古い候補、先の段階の行動、別の利用者の会話への操作を拒否し、同一送信の再試行は二重に進めない。相性の振り返りは任意の補助機能として維持する。

## 今回の範囲と次の評価

対象はMiraのカフェ体験。Asha、実際のマッチ相手、市場ルートは既存フローを維持している。翌日以降の永続保存は未実装で、サーバー再起動・期限切れで会話は終了する。

機能が動くことと面白さは別に評価する。人による試遊では「何を目指していたか」「自分の選択で何が変わったか」「別の選び方を試したいか」を確認する。結果が見えない・展開が単調という反応が残るなら、この小さなルートで調整してからAshaや市場へ広げる。
