# 友達に試してもらう手順

事前に常設公開するか、一時的にCloudflare Tunnelを再起動し、公開URLが実際につながることを確認する。現在の一時トンネルは停止中。作成者はローカル画面で成人確認をして分身を作り、返答を確認して承認する。ホームの「友達に分身を試してもらう」から招待リンクを作成する。リンクは7日間有効で、停止や分身の更新で利用できなくなる。

友達への案内文：

> これは私が確認・承認したAI分身と遊ぶデモです。私本人の気持ちや行動を予測するものではありません。18歳以上なら、リンクを開いて「招待された分身と話す」から3つの選択で短いデートを遊んでみてください。気が向けば自由に話して、最後に「二人の記録」を見てください。住所・連絡先・秘密は入力しないでください。

試遊後は次の3つだけ聞く。回答は匿名のメモとして残し、会話全文の提出は求めない。

1. どの場面が楽しかったか、または退屈だったか。
2. 分身の返答で違和感があった一例は何か。
3. この体験の後、本人に聞いてみたいことが一つ浮かんだか。

作成者がリンクを停止したら、訪問者の継続送信も拒否される。友達の会話全文は作成者に自動開示されない。人による試遊はまだ行っていない。結果を受けて会話とシーンを調整する。
