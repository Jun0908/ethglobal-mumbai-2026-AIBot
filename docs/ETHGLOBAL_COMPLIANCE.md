# ETHGlobal Mumbai 2026 compliance checklist

Last reviewed: **2026-11-06**. Verify changes in the official Hacker Dashboard immediately before submission.

Official sources:
- https://ethglobal.com/events/mumbai/info/start
- https://ethglobal.com/events/mumbai/info/details
- https://ethglobal.com/rules

## Timing and tracks
- Official Mumbai submission deadline: **Sunday 2026-11-08, 09:00 IST**.
- Classic / Start Fresh: event-specific code, designs and assets must be made **after official hackathon kick-off**; libraries and boilerplate are allowed.
- Continuity tracks permit pre-existing code under documented conditions; **team must confirm selected track**.
- Keep frequent, meaningful commits showing development chronology; avoid one giant initial code commit.
- Disclose pre-existing work and reused assets; distinguish what was created during event.

## AI-assisted development transparency
- Describe where ChatGPT/Codex/other AI contributed, which code/files/assets were assisted and what humans reviewed or implemented.
- Keep specifications, prompts and planning artefacts if using spec-driven development.
- Do not describe the entire output as solely autonomous AI work: event says meaningful human contributions are expected.

## Submission and presentation
- Submit project title/description and repo via Hacker Dashboard before deadline.
- Optional but encouraged demo video: **2–4 minutes**, at least **720p**; no sped-up recording, mobile-phone recording, AI voiceover/TTS, or music+text-only explanation.
- Up to **3 partner prize programs**, selected in dashboard.
- Finalist session if selected: **4 minutes demo + 3 minutes Q&A**.
- Confirm partner-specific conditions separately; do not assume PSI/ENS/Arkiv integration automatically qualifies.

## Safety and consent
- Respect ETHGlobal code of conduct; avoid sexualized hack/demo assets.
- Demo character(s) adult; obtain permission for any real person's persona, voice or face.
- Public repo contains **no raw participant answers, secrets, keys, private contact data or non-licensed media**.
