# Invited twin experience — 2026-11-07

The owner can create a seven-day invitation for an approved twin. The invite is a bearer link with a random secret. The server stores only its hash in an encrypted record, checks consent and capsule version on entry and every companion request, and lets the owner stop it. Reapproval makes earlier invitations unusable. An invited visitor must confirm that they are an adult before a session is created. The visitor sees the twin's chat, three-choice date and one-page dashboard; their conversation is isolated by an opaque browser cookie. The owner does not receive that transcript.

The game uses the approved first-meeting tendency and voice in its opening, the planning preference for suggestions, and the approved romance pace for its ending. Unknown traits keep neutral wording. The completed game opens the existing dashboard automatically. The dashboard keeps actual conversation topics separate from scripted game events; without real conversation evidence, the topic section stays empty. The Asha and Mira stories remain separate.

Verification: `npm test` (36 passing), `npm run build`, `node scripts/check-invite.mjs` against a production server, and `node scripts/check-identity-restart.mjs`. The invite check covers separate visitor records, three game choices, preference-specific wording, stopping a link and invalidation after persona reapproval. A browser walkthrough confirmed invite landing, adult confirmation, three choices, automatic recap and the illustrated plan in Japanese.
