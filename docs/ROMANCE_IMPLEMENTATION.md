# Miraの３話と相性の発見：実装記録

2026-11-07。第1版。ホームまたは相手一覧でMiraを選ぶと新しい物語を開始・再開する。Ashaと実マッチ相手は既存フロー。

## 実装したこと

- 雨宿り、撮影散歩、写真を見せる再会の３話。各話4つの決断に自由会話を挟める。
- 選択肢と自由入力から同じ出来事を進める。自由入力は既存OpenAI接続で意図を解釈し、サーバーが進行を確定する。寄り道の質問では進めない。
- 誘いを断る、好みが違う、友達として会いたい、という返答でも話を区切れる。
- 再会では前の発言を引用し、会話のペースや予定への希望に応じた台詞を出す。記憶を削除するとその根拠と再引用も削除する。
- 会話のペース、過ごし方、距離感、支え方の共通点・違いを双方の発言とともに表示。判断できない観点は未判定。根拠から会話履歴へ移動できる。
- 本人の任意の感想を記録。相性の数値・順位は付けない。
- 暗号化したサーバー保存と専用HttpOnly Cookie。サーバーを再起動しても同じブラウザで再開。最終利用から30日で期限切れ。Cookie削除・別端末での復元は対象外。
- 思い出の個別削除、全記録の削除、本編を保った別ルートの試遊、本編への復帰。
- Miraの元のイラストと新しい表情画像。通常・笑顔・照れ・迷いを切替。生成した表情アトラスのからかい顔は今後の演出用として同梱。
- JP/ENで画面・新しい台詞・選択肢を切替。過去の発言は原文のまま残す。

## 実装先

- `src/lib/romance-story.ts`：３話のJP/EN脚本、進行と関係の記録、再会、自由入力の進行制限。
- `src/lib/server/romance-store.ts`：暗号化保存、読み込み、削除、期限切れ。
- `src/app/api/romance/route.ts`：所有者Cookie、入力・revision・再送検証、自由会話、記憶操作、試遊。
- `src/components/romance-experience.tsx`：場面、台詞、返答、履歴、思い出帳と根拠。
- `scripts/check-romance.mjs`、`tests/romance-story.test.ts`：状態とAPIの検証。

既存の引用振り返りAPIは維持。新体験の観察は、明示的な返答と台本の双方の発言を直接参照する方式。自由会話全体からの新しい観点の抽出や「歩み寄れた」の自動判定は、この版には追加していない。

## 確認結果

- 状態テストを含む `npm test`：24件成功。`npm run typecheck` と `npm run build` 成功。
- `TEST_BASE_URL` を3000番に指定した `node scripts/check-romance.mjs`：３話、不同意、再会、古いrevision、別Cookieの分離、根拠削除、感想、独立試遊から復帰、再送、全削除が成功。
- 実OpenAI接続：寄り道の質問は進行せず、明示した会話ペースの自由入力は進行。終了後の自由会話も応答する。
- サーバー停止後に本番サーバーを起動し、保存済みCookieから同じrevision・発言IDの復元を確認。
- ブラウザ：日本語の初対面から再会、英語へ切替、好みの違いと友達としての結末、根拠表示を確認。390px幅で横はみ出しなし。
- 試験中、関連する質問をLLMが選択肢と広く解釈したため、質問を保守的に保留するサーバー側の判定を追加した。任意の表現を完全に認識できる保証ではない。
